# 卡爾曼濾波器（一）：直覺與一個數字的版本

## 一句話

每一步先用模型猜，再看真實量測修正，修正多少看兩邊誰比較可靠。

## 白話解釋

這一頁的目標是讓你**看得懂、也算得出**卡爾曼濾波器的公式，先從只追蹤一個數字的版本開始，分四層。第二頁 [[kalman-velocity]] 再加入速度和矩陣。想動手玩，可以開[拖拉實驗頁](kalman-lab.html)。

### 第 1 層：先懂兩個詞

**還沒讀過的話，先讀 [[variance-normal]]**：它從「平均」講到變異數和鐘形曲線，這一頁的所有公式都建立在它上面。

- **估計值**：你對「真正的價格」的最佳猜測。真正的價格看不到，只能猜。
- **變異數**：在這裡用來表示「有多沒把握」，越大越沒把握。猜 100、標準差 1（變異數 1），代表大概在 99 到 101 之間；標準差 2（變異數 4），大概在 98 到 102 之間。

### 第 2 層：一個直覺，兩個人報價

兩個人告訴你同一個價格：
- 甲說 100，他有點沒把握（變異數 1.5）。
- 乙說 102，他更沒把握（變異數 2）。

最合理的做法是**加權平均，越有把握的人權重越大**。數學上，權重剛好是「**對方**的變異數」佔總和的比例：

$$\text{結合後} = 100 \times \frac{2}{1.5+2} + 102 \times \frac{1.5}{1.5+2} = 100.86$$

同一條式子也可以改寫成「從甲的數字出發，往乙走一段」：

$$\text{結合後} = 100 + \underbrace{\frac{1.5}{1.5 + 2}}_{0.429} \times (102 - 100) = 100.86$$

括號下面標著 0.429 的那一項，就是**卡爾曼增益 $K$**。卡爾曼濾波器做的事，就是每天把「自己的預測」（甲）和「看到的價格」（乙）這樣結合一次。

這個公式從哪來：把兩個人的說法各畫成一條鐘形曲線，兩條相乘會得到一條更窄的新鐘形曲線，它的中心就是上面算的 100.86。

見 [[kalman-gaussian-2012]]，以及 [[variance-normal]] 的「性質二」。

### 第 3 層：一個數字的完整公式

假設：
- 真正價格每天隨機晃一點，晃動的變異數叫 $Q$（過程雜訊）。
- 看到的價格 = 真正價格 + 雜訊，雜訊的變異數叫 $R$（量測雜訊）。

**先看懂符號**（全部只有這幾個）：

| 符號 | 讀法 | 意思 |
|---|---|---|
| $t$、$t-1$ | 今天、昨天 | 下標寫在字母右下角，表示是哪一天的值 |
| $y_t$ | y | 今天看到的收盤價（量測） |
| $\hat{x}_t$ | x hat | 今天真正水位的**估計**。帽子 ^ 表示「估計出來的」 |
| $P_t$ | P | 這個估計有多沒把握（變異數） |
| $\hat{x}^-_t$、$P^-_t$ | x hat minus | 右上角的減號表示「**修正前**」，也就是只靠預測、還沒看到今天價格時的值 |
| $K_t$ | K | 卡爾曼增益：今天要往量測走多少比例 |

每天兩步、五條公式：

**① 預測**（還沒看到今天的價格）

| 公式 | 白話 |
|---|---|
| $\hat{x}^-_t = \hat{x}_{t-1}$ | 沒有新資訊，猜「跟昨天一樣」 |
| $P^-_t = P_{t-1} + Q$ | 過了一天，真正價格又晃了一下。兩個互不相關的不確定性相加，變異數直接相加（[[variance-normal]] 性質一） |

**② 修正**（看到今天的價格 y）

| 公式 | 白話 |
|---|---|
| $K_t = \dfrac{P^-_t}{P^-_t + R}$ | 我的猜測有多不可靠，佔全部不可靠的比例 |
| $\hat{x}_t = \hat{x}^-_t + K_t\,(y_t - \hat{x}^-_t)$ | 從猜測往量測走 $K$ 的比例 |
| $P_t = (1 - K_t)\,P^-_t$ | 多看了一筆資料，比較有把握了 |

$y_t - \hat{x}^-_t$ 叫**創新值**：量到的和猜的差多少，也就是「這次有多意外」。

**K 一定在 0 和 1 之間**（[[kalman-course-2001]] 第 4.1.2 節）：
- $R$ 很大（價格很吵）→ $K \to 0$ → 不太理會新價格。
- $P^-$ 很大（自己很沒把握）→ $K \to 1$ → 幾乎直接用新價格。
- $P^- = 0$ → $K = 0$ → 永遠不更新。所以一開始的 $P$ 不能設成 0。

### 第 4 層：Q 和 R 怎麼調

這兩個數字決定了濾波器的「個性」：

| 你把… | K 會… | 估計線會… |
|---|---|---|
| R 調大 | 變小 | 比較平滑，但慢半拍 |
| R 調小 | 變大 | 反應快，但跟著雜訊亂跳 |
| Q 調大 | 變大 | 比較相信「價格會變」，跟得比較緊 |
| Q 調小 | 變小 | 比較相信「價格不太變」，比較平滑 |

[[kalman-course-2001]] 用實驗示範：真實雜訊的變異數是 0.01，R 設成 1（大 100 倍）時，濾波器很慢才相信量測；設成 0.0001（小 100 倍）時，很快就相信雜訊很大的量測，估計跟著亂跳。實務上，R 可以事先量（看價格本身有多吵），Q 比較難定，通常要調。

**和移動平均的關係**：Q、R 固定時，K 會很快穩定成一個固定值（[[kalman-course-2001]] 第 5.1 節）。K 固定之後，「每天往新價格走固定比例」就是**指數移動平均**。所以最簡單的卡爾曼濾波器等於一條最佳化過的指數移動平均，這也是 [[kalman-trend-2016]] 引用的結論。

### 下一步：加入速度

到這裡為止的模型只追蹤一個數字，它的預測永遠是「跟昨天一樣」，所以給不出漲或跌的方向，還不能拿來交易。加入「速度」、改用矩陣，以及實際拿來交易時每天的流程，在下一頁 [[kalman-velocity]]。

## 例子

### 手算一遍

設定：一開始估計 $\hat{x}_0 = 100$、$P_0 = 1$；$Q = 0.5$、$R = 2$。接下來四天看到的價格是 102、101、105、104。（數字是示意，Wiki 用程式驗算過。）

| 天 | 看到 $y_t$ | 預測 $\hat{x}^-_t$ | $P^-_t$ | $K_t$ | 創新值 | 修正後 $\hat{x}_t$ | 修正後 $P_t$ |
|---|---|---|---|---|---|---|---|
| 1 | 102 | 100.00 | 1.500 | 0.429 | +2.00 | 100.86 | 0.857 |
| 2 | 101 | 100.86 | 1.357 | 0.404 | +0.14 | 100.91 | 0.809 |
| 3 | 105 | 100.91 | 1.309 | 0.395 | +4.09 | 102.53 | 0.791 |
| 4 | 104 | 102.53 | 1.291 | 0.392 | +1.47 | 103.11 | 0.785 |

第 1 天：

1. 預測：$\hat{x}^-_1 = 100$，$P^-_1 = 1 + 0.5 = 1.5$
2. 增益：$K_1 = \dfrac{1.5}{1.5 + 2} = 0.429$
3. 修正：$\hat{x}_1 = 100 + 0.429 \times (102 - 100) = 100.86$
4. 新的不確定性：$P_1 = (1 - 0.429) \times 1.5 = 0.857$

第 1 天的數字和第 2 層「兩個人報價」完全一樣：甲就是預測（100，變異數 1.5），乙就是看到的價格（102，變異數 R = 2）。

觀察：
- 價格跳到 102，估計只走到 100.86，因為 R 很大，濾波器懷疑這是雜訊。
- K 從 0.429 慢慢降，跑久了穩定在約 0.39。

### 自己算算看

1. 預測 $\hat{x}^- = 50$，$P^- = 4$，$R = 4$，看到 $y = 54$。$K$、修正後的 $\hat{x}$、修正後的 $P$ 各是多少？
2. 同上，但 $R$ 改成 12。$K$ 和 $\hat{x}$ 變成多少？和第 1 題比，為什麼？
3. 如果 $P^- = 0$ 呢？
4. 不用算：把 Q 調大，估計線會變得比較平滑還是比較貼價格？

答案在本頁最下面。

**「自己算算看」的答案**

1. $K = \frac{4}{4+4} = 0.5$；$\hat{x} = 50 + 0.5 \times 4 = 52$；$P = (1 - 0.5) \times 4 = 2$。
2. $K = \frac{4}{4+12} = 0.25$；$\hat{x} = 50 + 0.25 \times 4 = 51$。量測更吵（R 變大），所以只往它走四分之一。

4. 比較貼價格。$Q$ 大 → $P^-$ 大 → $K$ 大 → 每次往新價格走更多。
